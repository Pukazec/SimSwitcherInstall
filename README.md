# Step 1 — Download
 
1. Go to the [Sim Switcher GitHub repository](https://github.com)
2. Click the green **`< > Code`** button near the top right
3. Select **Download ZIP** from the dropdown menu
 
---
 
## Step 2 — Extract
 
1. Locate the downloaded `.zip` file (usually in your **Downloads** folder)
2. Move it to the folder where you want Sim Switcher to live
3. Right-click the `.zip` file and select **Extract All...**, then confirm
 
> 💡 **Tip:** Choose a permanent location before extracting — moving the folder after installation may cause issues.
 
---
 
## Step 3 — Install
 
1. Open the extracted folder
2. Double-click the **`.bat`** file to run it
3. If Windows shows a security warning, click **More info → Run anyway**
 
The installer will take care of the rest. You're all set! 🎉
 
---
 
## Troubleshooting
 
- **The `.bat` file doesn't run** — Make sure you fully extracted the ZIP. Running files directly inside a ZIP archive won't work.
- **Windows blocks the file** — This is normal for unsigned scripts. Click **More info** on the warning popup, then **Run anyway**.
